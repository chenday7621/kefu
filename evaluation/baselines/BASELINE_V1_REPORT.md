## Known limitations and blockers for formal Baseline V1

1. Formal DEV and HELDOUT have not been run by design.
2. Human Judge calibration has not been completed.
3. The direct provider showed an intermittent Rewrite timeout during preflight.
4. One hundred records lack reliably reconstructed evidence text.
5. Reference answers remain primarily Silver; only the documented ID 65 source
   binding has the explicit `verified` status.
6. The provider does not expose a hosted weight/revision digest.
7. KG is disabled until the train-only runtime graph is built and audited.

The Candidate can become a clean committed experimental starting point, but the
formal readiness result remains `BASELINE_V1_READY = NO` until the separately
authorized DEV/HELDOUT execution and remaining validation gates are complete.
